# MagNet
MagNet es una aplicación web que permite a personas en búsqueda de empleo a encontrar ofertas laborales acordes a su perfil. El sistema recopilará ofertas desde la Web y las analizará según los conocimientos, experiencia, preferencias y objetivos de cada usuario, generando recomendaciones personalizadas y mostrando el nivel de compatibilidad con cada oferta.

## Descripción del Problema
Existe una gran cantidad de ofertas laborales, con requisitos y características diversas, lo que dificulta a las personas en búsqueda de empleo identificar de manera rápida aquellas oportunidades que realmente se ajustan a su perfil, habilidades, intereses y preferencias. 

## Usuarios Objetivo
Personas que se encuentren en búsqueda activa de empleo y utilicen plataformas web para consultar y postular a ofertas laborales, independientemente de su área profesional o nivel de experiencia. 

## Objetivos
Brindar a los usuarios ofertas laborales acordes a su perfil, indicando un índice de compatibilidad y las características o requisitos que podrían faltar para mejorar su correspondencia con cada oferta. 

## Alcance y Exclusiones
### Incluye: 
* Crear y gestionar cuentas de usuario.
* Registrar y modificar información del perfil.
* Registrar áreas de interés y preferencias laborales.
* Consultar ofertas de empleo obtenidas desde fuentes web externas.
* Filtrar ofertas según distintos criterios.
* Calcular y mostrar la compatibilidad entre el perfil del usuario y las ofertas laborales.
* Identificar características o requisitos de las ofertas que no están presentes en el perfil del usuario.
* Redirigir al usuario al sitio original para realizar una postulación.

### Excluye
* Realizar directamente el proceso de contratación
* Gestionar la postulación dentro de los portales externos.

## Funcionalidades principales
* Visualizar ofertas laborales.
* Filtrar ofertas.
* Adjuntar CV.
* Crear perfil profesional.
* Buscar ofertas compatibles.
* Visualizar índice de compatibilidad.
* Identificar requisitos faltantes.
* Redirigir a la plataforma original para postular.

## Funcionalidades avanzadas/futuras
* Transformación del CV a formato LaTeX.
* Adaptación automática del CV a una oferta específica, con autorización del usuario y sin generar información falsa.

## Fuente de información web
Portales de empleo externos, inicialmente considerando fuentes como ChileTrabajos, Laborum, FirstJob, Indeed o Computrabajo. La selección definitiva de las fuentes dependerá de su disponibilidad, estructura, mecanismos de acceso y condiciones de uso. 

## Capacidad adaptativa
MagNet personalizará las ofertas laborales mostradas a cada usuario en función de información de su perfil, como áreas de interés, habilidades, experiencia, ubicación y preferencias laborales. A partir de estas variables, el sistema calculará un índice de compatibilidad entre el perfil del usuario y cada oferta, priorizando aquellas que presenten mayor correspondencia e indicando los requisitos o características que el usuario no cumple.
